### 2. 监控程序修改 (`realtime_monitor_v2.py`)

#### 修改1: `__init__()` 方法
- 添加 `self.sample_interval_minutes` 计算采样间隔（分钟）
- 修改历史深度计算逻辑，支持小数时间窗口
- 例如：5分钟窗口，30秒采样 = 5 / 0.5 + 1 = 11个点

```python
self.sample_interval_minutes = SAMPLE_INTERVAL / 60  # 0.5分钟
self.max_history = int(self.max_window / self.sample_interval_minutes) + 1
```

#### 修改2: `_calculate_change()` 方法
- 参数类型从 `int` 改为 `float`，支持小数时间窗口
- 计算需要的采样点数：`samples_needed = int(window_minutes / self.sample_interval_minutes)`
- 例如：30秒(0.5分钟) / 0.5 = 1个点，取 `history[-2]`
- 例如：5分钟 / 0.5 = 10个点，取 `history[-11]`

#### 修改3: `_setup_rules()` 方法
- 添加时间窗口格式化显示
- 小于1分钟显示为"秒"，否则显示为"分钟"

```python
if window < 1:
    window_text = f"{int(window * 60)}秒"
else:
    window_text = f"{int(window)}分钟"
```

#### 修改4: `_sample_loop()` 方法
- 显示所有时间窗口的TOP5（不再只显示最小窗口）
- 自动获取所有不同的时间窗口并排序
- 遍历每个窗口，分别显示涨幅榜和跌幅榜
